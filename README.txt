ULTRON FREE DEMO (static web app)

This demo has a working UI and stores chat history on this device, but it does NOT contain a generative AI model.

Free hosting option: GitHub Pages
1. Create/sign in to GitHub.
2. Create a new public repository named ultron-demo.
3. Upload these project files into the repository root.
4. In the repo, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and / (root), Save.
6. Wait for the Pages link to appear. Open it in Chrome.
7. Chrome menu (⋮) > Add to Home screen / Install.

Keep passwords and API keys private. A genuine AI connection may need an API account, and some providers charge or require adult account permission. Don't put API keys in browser files or public repositories.
